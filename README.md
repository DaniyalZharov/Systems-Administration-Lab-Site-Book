# Windows and Linux Systems Administration Lab

Academic systems administration project completed by Daniyal Zharov
for NSSA 221 at Rochester Institute of Technology.

## Overview

This site book documents a five-machine virtual lab containing a
pfSense router, Windows Server 2022 domain controller, Windows 11
client, Rocky Linux client, and Rocky Linux storage server.

## Areas Covered

- Active Directory users, organizational units, and Group Policy
- DNS and DHCP configuration
- Windows and Linux networking
- RAID 1 and RAID 5 storage and persistent mounts
- Samba, NFS, FTP, and rsync file-sharing services
- Bash scripting and cron scheduling
- Backup, disk-usage, and network-monitoring tasks
- Configuration documentation and validation
